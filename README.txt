MY ENGLISH HOUSE — autonomous web app

How to use
1. Extract the ZIP archive if necessary.
2. Open index.html with a modern browser (Chrome, Edge, Firefox or Safari).
3. No installation, account or internet connection is required for the activities.

Audio note
English pronunciation uses the browser's Web Speech API. Voice availability and offline operation depend on the browser and device. The “Audio on” button can switch to text mode.

Privacy
The app does not send data to a server. Progress and anonymous activity results stay in the browser's local storage. Teacher mode can export a CSV summary.

Main contents
- Explore three rooms and eleven furniture words.
- Listening, instruction, matching, grammar and optional numbers activities.
- Bedroom designer with PNG export.
- Short final challenge.
- Teacher settings, local progress and CSV export.
